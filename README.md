# 墨阁 · 网文写作工坊（离线版）

一款专为网络小说作者打造的**完全离线、无需登录**的本地写作软件。所有数据保存在本机，不联网、不上传、无广告。

## 快速开始

### 方式一：免安装 EXE 版（推荐，无边框窗口）
双击 `墨阁写作工坊-免安装版.exe` 即可使用，无需安装、无需联网。
- 无原生窗口边框：顶部标题栏即拖拽区（双击最大化），右上角有最小化/最大化/关闭按钮
- 数据保存在本机应用数据目录（`%APPDATA%\墨阁写作工坊`），与浏览器版互不影响
- 导出文件时会弹出「另存为」对话框，方便选择保存位置
- 重复打开只会聚焦已有窗口，不会开多个实例

### 方式二：直接双击打开（网页版）
双击 `index.html`，用 Chrome / Edge / Firefox 打开即可使用。

### 方式三：本地服务器（如 file:// 打开异常时）
在 `novel-studio` 目录下打开终端执行：

```bash
python -m http.server 8080
# 然后浏览器访问 http://localhost:8080
```

### 数据存放位置
- EXE 版：`%APPDATA%\墨阁写作工坊`（应用数据目录）
- 网页版：浏览器 IndexedDB 中（对应浏览器配置文件目录）

**重要：清理数据/重装前，请先在「设置 → 数据备份」导出 JSON 备份。** 两个版本之间可用「导出全部数据 / 导入数据」互相迁移。

### 重新打包 EXE（开发用）
在 `novel-studio` 目录执行：

```bash
npm install
npm run dist   # 产物在 dist/墨阁写作工坊-免安装版.exe
```

## 功能总览

| 模块 | 功能 |
| --- | --- |
| 书架 | 多作品管理、封面/类型/状态/简介、总字数与今日字数 |
| 写作 | 章节编辑器、自动保存（间隔可自定义）、码字模式（沉浸式全屏）、上一章/下一章、实时字数、**码字时长/速率/暂停计时**、章节树高亮当前编辑章节、**细纲与写作备注并排（宽栏）** |
| 章节 | 卷/章节树、章节细纲、写作备注、状态（草稿/定稿/已发布）、**拖拽排序**（章节同卷/跨卷/拖入卷，卷排序） |
| 大纲 | 任意数量大纲文档（总体大纲、分卷细纲…） |
| 设定 | 人物、势力、地点、物品、功法等**统一设定列表**（按类型过滤 + 搜索），人物卡含外貌/性格/背景/关系/标签 |
| 关系图 | 可视化人物关系图：拖拽节点、缩放平移、自动布局、**三种关系模式**（A→B 单向 / A⇋B 互为 / A⇋B 各自关系双标签）、16 种常用预设、位置持久化，与人物卡联动 |
| 伏笔 | 伏笔埋设/回收跟踪，一键标记回收 |
| 时间线 | 故事内事件时间线，自动按时间排序 |
| 灵感 | 全局灵感库 + 各作品灵感，标签管理 |
| 统计 | 全年写作热力图、连续写作天数、近30天日均、各卷字数、每日目标 |
| 检查 | 违禁词/敏感词检查（内置示例词表 + 自定义词表）、错别字检查（内置80+常见词对 + 自定义词对）、一键替换 |
| 起名 | 离线姓名生成器（性别/风格）、笔名生成器，点击复制 |
| 导出 | TXT 全文（含目录，可直接投稿）、**Word (DOCX)**、**PDF（打印另存，中文完美）**、**EPUB 电子书**、**HTML 网页**、**RTF（Word/WPS 兼容）**、Markdown、单章 TXT、JSON 备份 |
| 备份 | 每日自动备份（保留15份）、手动备份、一键恢复、全量导入/导出 |
| 外观 | 浅色/深色/跟随系统、宋体/楷体/黑体等正文字体、字号与行距调节 |

## 写作常用快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+S` | 立即保存当前章节 |
| `Ctrl+Enter` | 保存并跳到下一章 |
| `Esc` | 退出码字模式 |
| `Ctrl+Shift+F` | 全局搜索 |

## 使用建议（面向网文作者）

1. **码字模式**：写正文时点右上角「⛶ 码字模式」，只保留文字与字数进度，进入心流。
2. **细纲先行**：每章先写细纲再动笔，正文区上方可随时查看细纲面板。
3. **每日目标**：在「统计」或「作品设置」里设置目标字数，配合热力图保持连更。
4. **投稿前检查**：在「总览」点「全本检查」，或编辑器中点「检查」，在「设置」中按平台要求补充违禁词表。
5. **定期备份**：每天首次打开自动备份；重要节点请手动「立即备份」并「导出全部数据」。
