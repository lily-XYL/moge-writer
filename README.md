# 墨阁 · 网文写作工坊（离线版）

一款专为网络小说作者打造的**本地优先、无需登录**的写作软件。写作、管理、检查、导出与备份均在本机完成；仅当用户主动配置并调用 AI 辅助写作时，才会联网向用户选择的 API 服务发送已勾选的上下文内容。

## 快速开始

### 方式一：免安装 EXE 版（推荐，无边框窗口）
双击 `墨阁写作工坊-修复版.exe` 即可使用，无需安装。除主动调用 AI 辅助写作外，日常写作无需联网。
- 无原生窗口边框：顶部标题栏即拖拽区（双击最大化），右上角有最小化/最大化/关闭按钮
- 数据保存在本机应用数据目录（`%APPDATA%\墨阁写作工坊·修复版`），与浏览器版互不影响
- 导出文件时会弹出「另存为」对话框，方便选择保存位置
- 重复打开只会聚焦已有窗口，不会开多个实例

### 方式二：直接双击打开（网页版）
双击 `index.html`，用 Chrome / Edge / Firefox 打开即可使用。

### 方式三：本地服务器（如 file:// 打开异常时）
在 `moge-writer-plus` 目录下打开终端执行：

```bash
python -m http.server 8080
# 然后浏览器访问 http://localhost:8080
```

### 数据存放位置
- EXE 版：`%APPDATA%\墨阁写作工坊·修复版`（应用数据目录）
- 网页版：浏览器 IndexedDB 中（对应浏览器配置文件目录）

**重要：清理数据/重装前，请先在「设置 → 数据备份」导出 JSON 备份。** 两个版本之间可用「导出全部数据 / 导入数据」互相迁移。

### 重新打包 EXE（开发用）
在 `moge-writer-plus` 目录执行：

```bash
npm install
npm run dist   # 产物在 dist/墨阁写作工坊-修复版.exe
```

| 伏笔 | 伏笔埋设/回收跟踪，一键标记回收 |
| 时间线 | 故事内事件时间线，自动按时间排序 |
| 灵感 | 全局灵感库 + 各作品灵感，标签管理 |
| 统计 | 全年写作热力图、连续写作天数、近30天日均、各卷字数、每日目标 |
| 搜索与替换 | 全局搜索支持全部作品、全书、卷和章节范围；正文批量替换支持相同范围、替换前统计与二次确认 |
| 起名 | 离线姓名生成器（性别/风格）、笔名生成器，点击复制 |
| 导出 | TXT 全文（含目录，可直接投稿）、**Word (DOCX)**、**PDF（打印另存，中文完美）**、**EPUB 电子书**、**HTML 网页**、**RTF（Word/WPS 兼容）**、Markdown、单章 TXT、JSON 备份 |
| AI 辅助写作 | 右侧可隐藏侧栏；默认 DeepSeek（`https://api.deepseek.com` / `deepseek-chat`）；支持多个本机 API 档案与独立加密 Key，可按需选择任意最多 6 个章节、全书大纲和作品设定作为引用，引用项默认关闭并限量发送 |
| 备份 | 可配置定时快照、退出前保护、导入/恢复/批量替换前保护备份；定时/退出/操作前备份默认保留30份，每日备份保留7份；Windows EXE 版支持选择外部文件夹并按自定义天数自动导出完整 JSON |
| 外观 | 浅色/深色/跟随系统、宋体/楷体/黑体等正文字体、字号与行距调节 |

| --- | --- |
| `Ctrl+S` | 立即保存当前章节 |
| `Ctrl+Enter` | 保存并跳到下一章 |
| `Esc` | 退出码字模式 |
| `Ctrl+Shift+F` | 全局搜索 |

## 使用建议（面向网文作者）

1. **码字模式**：写正文时点右上角「⛶ 码字模式」，只保留文字与字数进度，进入心流。
2. **细纲先行**：每章先写细纲再动笔，正文区上方可随时查看细纲面板。
3. **每日目标**：在「统计」或「作品设置」里设置目标字数，配合热力图保持连更。
4. **投稿前检查**：在「总览」点「全本检查」，或编辑器中点「检查」，在「设置」中按平台要求补充违禁词表。
5. **定期备份**：设置页可调整定时快照间隔与保留数量；Windows EXE 版可选择外部文件夹并设置自动导出天数。重要节点仍建议「立即备份」并「导出全部数据」。
6. **AI 辅助写作**：在章节编辑器点「✨ AI」后，配置页默认已填入 DeepSeek 地址和模型，仅需填入 API Key。需要切换 DeepSeek、豆包或其他兼容接口时，新增独立 API 档案；需要跨章连贯时，再按需选择要引用的章节范围。

## 隐私声明

本软件无账号系统、无统计上报，写作数据默认只保存在本机。仅当你主动配置并点击 AI 生成功能时，软件才会把当前章节上下文及你勾选的引用内容发送到该 API 服务；API Key 仅保存在本机，不会写入作品、备份或源码。
